# Support Information 🛠️ (URTC-DEVTOOLS)

Thank you for using URTC-DEVTOOLS! Here is how you can get help:

## 📺 Video Tutorials & Demos
The official YouTube channel covers the ecosystem's tools:
[youtube.com/@electrohobby3d](https://youtube.com/@electrohobby3d)

## ✉️ Direct Technical Inquiries
For questions about the shared tools, the lock file or how a repository can take the set:
Email: `electrohobby3d@gmail.com`

## 🐛 Bug Reports
If a shared tool refuses something it should accept, accepts something it should refuse, or a lock reports a copy wrongly, please open a **GitHub Issue** in this repository and name the file and the repository where you saw it.
*Please search existing issues before opening a new one.*

## ❌ What is NOT support?
- Questions about running a specific program belong in that program's own repository.
- Please do not use Issues for "How to" questions.
